# HerNest Solutions Website
Responsive multi-page static website starter based on the supplied brief.

## Preview
Open `index.html` in a browser or upload the folder to your static hosting account.

## Included
- Home, Services, AI Automation, Web Design, AI Marketing, About, Contact, Privacy Policy, Terms of Service
- Responsive navigation and mobile menu
- SEO titles, descriptions, Open Graph basics
- Uses the supplied favicon.ico with a matching lavender and plum colour palette
- Contact form validation and email-draft handoff

## Before publishing
1. Confirm `hello@hernestsolutions.com` is the business email you want to publish.
2. Connect the form to a secure form backend if submissions should be delivered without opening the visitor's email app. Add spam protection.
3. Review Privacy Policy and Terms of Service and fill in the effective date/legal details.
4. Confirm every listed service is available to deliver.
5. Add real social links and configure analytics only if desired.
6. Test pages on mobile and desktop before launch.
